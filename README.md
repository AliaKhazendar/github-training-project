# github-training-project
# Kotlin Compose Training Project

## Description
A simple mobile app built with Jetpack Compose to display product categories, products, and a login screen.  
This project is part of a Git & GitHub training assignment to practice commits, branches, pull requests, and project organization.

## Technologies Used
- Kotlin
- Jetpack Compose
- Android Studio
- Material3

## How to Run
1. Open the project in Android Studio.
2. Build the project.
3. Run the app on an Android emulator or device.
4. Ensure you have Kotlin and Compose libraries installed.
